
# QuickNotes

QuickNotes is a simple, responsive web application for creating and managing personal notes.

## Features

- Add notes with Personal, Work, or Study categories.
- Validate note input and limit notes to 200 characters.
- Display the date and time each note was created.
- Delete individual notes.
- Search notes by text.
- Save notes in the browser using localStorage.
- Display the total number of saved notes.
- Responsive layout for desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server, or open it directly in a web browser.
4. Start creating and managing notes.

## Project Structure

```text
quicknotes-app/
├── index.html

├── script.js
└── README.md
```

## Data Storage

Notes are saved in the browser's localStorage. They remain available after refreshing the page in the same browser, but are not automatically shared between different browsers or devices.
